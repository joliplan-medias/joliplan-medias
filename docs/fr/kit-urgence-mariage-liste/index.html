Qui porte le kit

Confiez le kit à une personne qui reste près de vous toute la journée, par exemple un témoin. Ainsi, vous n'avez à penser à rien.

Écrivez un nom sur chaque enveloppe de prestataire pour éviter les confusions. Cette liste reprend 12 essentiels : ajoutez ce dont vous avez personnellement besoin, comme un traitement médical.
